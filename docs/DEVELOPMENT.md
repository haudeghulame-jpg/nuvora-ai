# دليل التطوير (من الهاتف)

هذا الملف جديد. لا يغيّر `README.md` ولا `CLAUDE.md` ولا `docs/PRODUCT_SPEC_AR.md` ولا `docs/ROADMAP.md`، وتبقى هذه الملفات هي المرجع.

يُكتب المشروع ويُفحص بالكامل عبر GitHub. لا تحتاج حاسوباً ولا Node.js ولا أي أمر في الطرفية.

## كيف يتم العمل

1. يعمل Claude على الفرع `phase-1-skeleton` فقط. لا أحد يدفع إلى `main`.
2. كل خطوة صغيرة تُحفظ في commit برسالة واضحة.
3. بعد كل دفع، يشغّل GitHub Actions الفحوص تلقائياً.
4. لا يُدمج شيء في `main` إلا بعد موافقتك الصريحة.

## كيف تتأكد من نتيجة الفحص من هاتفك

1. افتح تطبيق GitHub ثم المستودع `nuvora-ai`.
2. اختر تبويب **Actions**.
3. اختر آخر تشغيل في الأعلى، واسمه **CI**.
4. علامة ✓ خضراء تعني أن كل الخطوات الإلزامية نجحت، وعلامة ✗ حمراء تعني أن خطوة فشلت. افتح التشغيل لترى أي خطوة فشلت، وأرسل لي اسمها ونص الخطأ.
5. لتقرأ تقرير الثغرات (`npm audit`)، افتح داخل التشغيل خطوة **Security audit report**.

## ما الذي يفحصه CI

| الخطوة | ماذا تعني | هل تُفشل البناء؟ |
| --- | --- | --- |
| Install dependencies | تثبيت الحزم | نعم |
| Security audit report | تقرير الثغرات في الحزم | لا، للمعلومات فقط |
| Lint | فحص جودة الكود (ESLint) | نعم |
| Formatting check | فحص تنسيق الكود (Prettier) | لا، للمعلومات حالياً |
| Typecheck | فحص الأنواع (TypeScript) | نعم |
| Tests | الاختبارات الآلية (Vitest) | نعم |
| Production build | بناء النسخة النهائية (Next.js) | نعم |

إذا تغيّرت الحزم في `package.json` فإن CI يحدّث الملف `package-lock.json` تلقائياً، ثم يحفظه في الفرع (وليس في `main`) بعد نجاح كل الفحوص.

## متطلبات التشغيل المحلي (لمطوّر آخر لاحقاً)

لا تحتاجها أنت. تُذكر هنا للتوثيق فقط.

- Node.js بإصدار 22.12 أو أحدث.
- الأوامر: `npm install` ثم `npm run dev` للتطوير، و`npm run lint` و`npm run typecheck` و`npm test` و`npm run build` للفحص.
- المتغيرات البيئية: انسخ `.env.example` إلى `.env.local` عند الحاجة. لا توجد متغيرات مطلوبة في المرحلة 1.

## قواعد لا تُكسر

- لا مفاتيح أو كلمات سر داخل الكود أو المستودع. الأسرار في المتغيرات البيئية وفي كود الخادم فقط.
- لا خدمة مدفوعة ولا نطاق ولا استضافة بدون موافقتك.
- لا تغيير في Firebase أو المصادقة أو قاعدة البيانات قبل شرح الأثر وأخذ موافقتك.
- كل صفحة مؤقتة تحمل علامة واضحة بأنها نموذج غير متصل، ولا تُعرض بيانات وهمية كأنها حقيقية.
- لا نقول إن ميزة تعمل إلا بعد اختبارها فعلاً.
- الأرقام الغربية (0-9) في كل الصفحات بما فيها العربية.

## هيكل المشروع الحالي

- `src/app/`: صفحات التطبيق (Next.js).
- `scripts/`: أدوات مساعدة، ومنها تقرير الثغرات.
- `.github/workflows/ci.yml`: سير عمل الفحص التلقائي.
- `docs/`: التوثيق. الملفان `DEVELOPMENT.md` و`DECISIONS.md` جديدان.

## الحالة الحالية

انظر وصف طلب الدمج على GitHub للحالة المحدّثة. هذا الملف لا يدّعي أن أي ميزة تعمل.
