# NUVORA AI

منصة تعليمية ذكية وتفاعلية تساعد الطلاب على الفهم، لا على الحصول على الإجابة فقط.

## الرؤية
بناء مدرس رقمي متعدد الوسائط يشرح الدروس بالطريقة الأنسب لكل مادة: نماذج ثلاثية الأبعاد عند الحاجة، ومحاكاة علمية، وسبورة رياضيات، وخرائط وخطوط زمنية.

## النسخة الأولى
- المدرس البصري التفاعلي.
- حل التمارين خطوة بخطوة.
- تلخيص الدروس والملفات.
- إنشاء اختبارات ذكية.
- مكتبة الطالب لحفظ أعماله.
- محادثة عامة بحدود استخدام واضحة.

## اللغات
العربية (افتراضية)، الفرنسية، والإنجليزية، مع دعم RTL للعربية وLTR للفرنسية والإنجليزية.

## مبادئ التطوير
- لا تغيّر أو تحذف ميزة قائمة عند تنفيذ طلب غير متعلق بها.
- لا تضع مفاتيح API أو الأسرار في الواجهة الأمامية.
- لا تعرض نماذج ثلاثية الأبعاد على أنها توليد جديد إذا كانت من مكتبة جاهزة.
- اختبر كل ميزة قبل دمجها.
- نفّذ العمل على مراحل صغيرة مع commits واضحة.
